# Deployment subset of requirements.txt, used by the Dockerfile.
#
# Excludes torch, open-clip-torch and the rembg package, and adds onnxruntime in
# their place. The engine keeps every feature: CLIP and u2netp run as
# pre-exported ONNX models fetched at build time, driven directly by
# app/server.py.
#
# The reason is the 512MB hosting ceiling. The Linux torch wheel is 554MB before
# its seven CUDA dependencies and CLIP ViT-B/32 in fp32 is another 605MB, while
# rembg pulls scipy, scikit-image, pymatting and pooch for roughly 100MB to
# drive one 4.6MB model. On onnxruntime, a 24MB wheel, the whole process peaks
# near 250MB with both models loaded.
#
# requirements.txt remains the original torch-based set for local use.
fastapi
uvicorn[standard]
opencv-python-headless
numpy
pytesseract
Pillow
onnxruntime
google-genai
python-dotenv
requests
python-multipart
